# POC Chat Client

## Requirements

* Node.js
* npm

## Setup

Install dependencies:

```bash
npm install
```

Create a `.env` file in the project root:

```env
NEXT_PUBLIC_API_URL=http://localhost:3000
```

Make sure the POC Chat server is running at the configured API URL.

## Run

Start the development server:

```bash
npm run dev
```

The client will run at:

```text
http://localhost:3001
```
